# Дуэль альянсов

## Что это за событие

«Дуэль альянсов» — недельное соревнование Last Asylum: альянс получает
соперника и шесть дней подряд набирает очки, каждый день — по своей теме.

| Параметр      | Значение                                                    |
| ------------- | ----------------------------------------------------------- |
| Формат        | альянс против альянса                                       |
| Кто участвует | альянсы от 20 участников из топ-32 по Мощи на сервере       |
| Когда         | с понедельника по субботу, по одному этапу в день           |
| Расчёт        | ежедневно в 05:00 МСК                                       |
| Зачёт         | победные очки этапа, личные очки, рейтинги за день и неделю |

Состав альянса для допуска фиксируется к воскресенью: учитываются альянсы
более чем с 20 участниками, входящие в топ-32 по Мощи на сервере.

:::warning

В «Осе» от каждого игрока ожидается минимум 10 000 000 очков дуэли за всю
неделю. Если по каким-либо обстоятельствам набрать их не получится,
предупредите R4/R5 — иначе вас могут исключить из альянса.

:::

## Когда проходит

Шесть этапов идут поочерёдно с понедельника по субботу, воскресенье — перерыв:

| День        | Этап          | Очки дуэли |
| ----------- | ------------- | ---------- |
| Понедельник | Ворон         | 1          |
| Вторник     | Строительство | 2          |
| Среда       | Технологии    | 2          |
| Четверг     | Герой         | 2          |
| Пятница     | Подготовка    | 2          |
| Суббота     | Рейд          | 4          |

Этап закрывается в 05:00 по Москве. Всё, что не успели сделать до этого
момента, уходит в зачёт следующего этапа, а не текущего.

## Общие правила

- Победитель определяется по сумме победных очков: у каждого этапа они свои,
  и побеждает сторона, набравшая больше к концу события.
- Набранные очки каждый день открывают награды дуэли (всего 9 этапов наград). Сундуки этапов 4–9
  открываются только через соответствующие технологии в дереве технологий
  Дуэли альянсов.
- Количество очков за действия зависит от исследованных технологий дуэли.
- Есть ежедневные и еженедельные рейтинги игроков по очкам; награды за
  рейтинг выдаются при ежедневном и еженедельном расчёте.

## Этапы

### Этап 1. Ворон — понедельник

| Задание                                   | Очки   |
| ----------------------------------------- | ------ |
| Расход 1 энергии                          | 150    |
| Выполнить 1 задание сокола                | 13 000 |
| Использовать 660 противоядия              | 1      |
| Купить набор, содержащий алмазы [1 Алмаз] | 30     |
| Собрать 100 зерна                         | 5      |
| Собрать 100 древесины                     | 5      |
| Собрать 60 трав                           | 5      |
| Требуется 1 вороний плод                  | 3      |
| Требуется 1 воронья эссенция              | 2 500  |

:::tip

- Совмещайте кормление ворона и трату энергии с этапом развития ворона в
  Битве на выживание: очки пойдут и в дуэль, и в БнВ
- Выполните задания сокола в воскресенье, но не собирайте награды. Соберите
  их утром понедельника — так разом закроется много заданий, а значит, и
  очков будет больше
- Отправьте отряды собирать ресурсы на грядках заранее, чтобы они вернулись
  после 05:00 МСК и принесли ресурсы уже в зачёт понедельника
- Очки даёт только сбор с ресурсных плиток
- Без необходимости не тратьте противоядие — оставьте его на четверг
- Эликсир и ягоды для ворона можно найти в лавке

:::

:::warning

Не открывайте сундуки ворона на этом этапе — они понадобятся на этапе 3,
где каждый открытый сундук снаряжения даёт очки.

:::

### Этап 6. Рейд — суббота

Боевой этап: акцент на атаке территорий вражеского альянса и очках за победу
над солдатами. Участвовать могут все участники альянса.

Весь день сидим под щитами и не снимаем их без необходимости.

Как это работает:

1. В меню дуэли наверху выберите вкладку «Рейд» (открывается только в
   субботу) и нажмите **Перейти** — откроется карта альянса соперника.
2. Найдите участников вражеского альянса без щитов или ресурсные плитки с их
   войсками. Поставьте своё святилище недалеко от врага.
3. Сражайтесь с врагом для набора очков. Очки дают именно за побеждённых
   солдат: даже если у противника не выставлена защита на стенах, очки
   начислятся, пока в его казармах остаются солдаты. Когда солдаты врага
   закончились, бить его смысла нет.
4. Чтобы вернуться, нажмите стрелку «назад» наверху карты или координаты из
   чата — откроется карта нашего сервера, где нужно поставить святилище.
5. По окончании этапа территории из других королевств автоматически вернутся
   в свои исходные королевства.

Перемещение между королевствами не расходует Продвинутые перемещения, а вот
перемещение внутри одного королевства — расходует. Механику перемещения через
рейд (когда мы проходим все шаги выше, не атакуя противника) мы называем
«телепорт через рейд».

| Задание                                              | Очки    |
| ---------------------------------------------------- | ------- |
| Купить набор, содержащий алмазы [1 Алмаз]            | 30      |
| Использовать ускорение строительства (1 мин)         | 65      |
| Провести 1 секретную операцию UR                     | 75 000  |
| Использовать ускорение исследований (1 мин)          | 65      |
| Применить ускорение тренировки (1 мин)               | 65      |
| Использовать ускорение лечения (1 мин)               | 65      |
| За каждого побеждённого солдата (в определённом бою) | 40      |
| За каждого побеждённого солдата                      | 8       |
| За каждого павшего солдата                           | 8       |
| Отправить UR караван                                 | 100 000 |

:::warning

Этап длится 24 часа. Поставьте щит и отключите в стене у своих отрядов опцию
«Присоединиться к обороне», иначе потеряете больше солдат.

:::

## Что требуется от участника альянса

- Знать, какой этап идёт сегодня, и тратить накопленное в «свой» день.
- На рейде ставить щит и снимать галки с отрядов на стенах.
