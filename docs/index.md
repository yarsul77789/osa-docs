# База знаний альянса Оса #242

Здесь собраны материалы по игре Last Asylum: механики событий, тактика альянса
и внутренние договорённости.

Статьи из этого раздела доступны двумя способами:

- на сайте — через меню слева;
- в Telegram-боте альянса — раздел **Обучение**.

Текст в боте и текст на сайте берутся из одних и тех же файлов, поэтому
расхождений между ними не бывает: правка в репозитории попадает и туда, и туда.

## Как добавить статью

1. Создать `.md`-файл в папке `docs/` репозитория.
2. В начале файла указать frontmatter с полями `title` и `sidebar_position`.
3. Запушить изменения в ветку `main` — сайт пересоберётся автоматически.
4. В боте нажать **Управление → Обновить список статей**.
